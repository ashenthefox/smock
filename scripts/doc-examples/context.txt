# The context that whole Definition files of the user documents leave out,
# which scripts/check-doc-examples.py gives each of them before it runs
# smock check. Each line gives one file to one example:
#
#   <document> <example> <path> <source>
#
# <example> is the example's number among the whole Definition files of
# <document>, counted from 1, as the check prints it beside the line of
# its fence. <path> is where the file goes in the example's definitions
# directory, and <source> the file of the tree it is a copy of. An example
# that its document shows whole needs no line.
