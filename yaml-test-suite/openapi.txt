# The cases of yaml-test-suite's data-2022-01-17 that smock's YAML parser
# does not pass in the mode for OpenAPI documents, each with its reason.
# scripts/check-yaml-test-suite.sh runs every case, and
# scripts/yaml-test-suite-verdict.py judges the testee's answers against
# this list. A line gives the case, why it is listed, and the reason:
#
#   differs   a known difference: smock reads the case otherwise on purpose,
#             and the documents list it.
#   skipped   the testee skips the case.
#   #<issue>  a bug: the case fails until that issue is done.
#
# A case that fails or is skipped without being listed so fails the run,
# and so does a listed case that passes: it must come off. A case with one
# of the constructs of yaml-test-suite/README.md's table is not listed
# here: it passes when smock refuses it with the message the documents
# give for that construct. The one exception is a case that smock refuses
# first for a known difference: it is listed as differs, and its reason
# says that it holds the construct too. Before a branch merges into main, this list may
# keep its bugs, each with its issue, until yaml's L4 ticket (#323) fixes
# them (docs/merging-into-main.md).
